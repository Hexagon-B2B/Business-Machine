# HEXAGON B2B — Sales & Business OS V1

Working frontend connected to your Supabase project.

## Features
- Login
- Dashboard with live counts
- Companies (list, search, create, detail)
- Tasks (create, mark done)
- Meetings & Calls (log interactions)
- Opportunities (pipeline)

## Local development
```bash
npm install
npm run dev
```
